# Prompt para retomar una sesión

Leé AGENTS.md, README, PROJECT_STATUS y ADR antes de tocar código. Inspeccioná rama/estado actual. Identificá la última etapa autorizada, evidencia y pendientes.

Retomá solamente el alcance pendiente ya autorizado. No reinicies desde cero, no repitas trabajo completado ni borres cambios. Si falta autorización para la siguiente etapa, presentá la próxima tarea concreta; si hay un bloqueo real, explicalo y continuá con lo independiente.

Al terminar actualizá PROJECT_STATUS con cambios, pruebas, decisiones y próxima tarea. No divulgues secretos ni uses datos reales para ejemplos.
